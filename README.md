# Task 14 - JavaScript Conditions and Logic Programs

## Overview

This project demonstrates the use of JavaScript loops, conditional statements, and logical operations to solve common programming problems. The output of all programs is displayed in the browser console.

## Features

The project performs the following operations:

1. **Sum of First N Natural Numbers**

   * Calculates and displays the sum of the first `n` natural numbers using a `for` loop.

2. **Multiplication Table**

   * Prints the multiplication table of a given number.

3. **Prime Number Check**

   * Determines whether a number is prime or not.

4. **Prime Factors**

   * Finds and displays the prime factors of a given number.

5. **Sum of Digits**

   * Calculates the sum of all digits in a number.

6. **Armstrong Number Check**

   * Checks whether a number is an Armstrong number.

## How to Run

1. Download or clone the project.
2. Open `index.html` in any modern web browser.
3. Open the browser's Developer Console:

   * Chrome: `F12` → Console
   * Firefox: `F12` → Console
4. View the program outputs in the console.
